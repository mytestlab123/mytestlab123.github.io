**Project:** governed AWS compliance remediation in a personal lab.

The central design separates **reasoning, authorization, execution, and verification**. AWS Config supplies compliance evidence; the agent explains and plans; server-owned logic binds exact scope; human approval and AgentCore Policy gate execution; direct provider readback determines whether the change actually succeeded.

## Core pattern

```text
AWS Config
   ↓ evidence
AI agent — read / explain / plan
   ↓
Server-owned exact scope
   ↓
Human Approve / Reject
   ↓
AgentCore Gateway + Policy
   ↓
Exact narrow tool
   ↓
AWS API
   ↓
Direct provider readback
```

:::tip[Reusable lesson]
The strongest idea is not "AI remediates AWS." It is **each layer answers a different question**: detection, recommendation, approval, policy authorization, execution, and verification remain separate.
:::
