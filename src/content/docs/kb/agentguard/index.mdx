**Project:** demonstrate **why an AI security agent can be trusted** when it proposes a sensitive action.

AgentGuard keeps the model away from authorization. A proposal is converted into a typed, deterministic object; policy returns an explicit decision; sensitive changes require a one-time human approval; proposal mismatch, replay, expiry, and drift fail closed.

## Core pattern

```text
Observed state
   ↓
Typed proposal
   ↓
Deterministic policy
   ├─ ALLOW
   ├─ DENY
   └─ APPROVAL REQUIRED
            ↓
       human approval
            ↓
   exact proposal revalidation
            ↓
      narrow executor
            ↓
     verify + audit
```

:::caution[Current proof boundary]
The current live AWS phase is **read-only WAF evidence**. Live mutation is not presented here as already proven; the controlled mutation sequence is the project’s designed next trust path.
:::
