**Project:** a public reference for working with ChatGPT, AWS MCP, GitHub Actions, OIDC, and Terraform without long-lived CI credentials.

The durable operating rule is:

> **MCP discovers and verifies; Git/IaC declares; OIDC CI/CD applies.**

## Core pattern

```text
ChatGPT / agent
  ├─ AWS MCP → inspect / diagnose / verify
  └─ Git → IaC → PR → Actions → OIDC → AWS
                                  ↓
                            MCP readback
```
