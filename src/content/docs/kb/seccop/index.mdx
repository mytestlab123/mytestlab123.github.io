## 🤖 What this project explores

SecCop is a public secure-agent learning lab. Its current operator path combines deterministic provider evidence with an explanatory agent while keeping remediation behind explicit approval and narrow execution boundaries.

The repository also preserves earlier harness experiments that separate an untrusted plan-producing model from deterministic validation and tool dispatch.

## Reusable themes

- **Model plans are untrusted input** until deterministic code validates them.
- **Tool contracts stay narrow** instead of exposing generic AWS mutation authority.
- **Provider facts and aliases** can be sanitized before becoming model-visible.
- **Human approval and verification** remain explicit parts of remediation.
- **Different sources can have different capabilities**: EC2 may have a real remediation lane while stored/container artifacts can remain read-only suggestions.
