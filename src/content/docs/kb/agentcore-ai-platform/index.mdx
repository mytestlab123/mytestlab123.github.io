## 🧠 What this project explores

A deliberately small platform-AI POC where applications use a platform key to access approved models through one controlled API rather than receiving AWS credentials directly.

The public repository also contains later experiments around Bedrock service-specific credentials, AgentCore Gateway/Policy, harness patterns, governed workflows, and developer-facing platform experience.

## Reusable themes

- **Model access as policy** — a project can be allowed one model and denied another.
- **Credentials are lifecycle objects** — issue, scope, expire, reveal carefully, and audit.
- **Gateway/Policy is a governance layer** — model intent is not enough to authorize a tool/action.
- **Developer experience matters** — governance has to remain understandable from project, playground, and logs views.
