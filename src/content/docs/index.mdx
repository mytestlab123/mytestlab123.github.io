## Why this exists

This is deliberately a **learning site**, not the final Amit engineering portal.

The goal is to discover what works well in Astro + Starlight first, then carry only the useful patterns into `amitkarpe.github.io`.

:::note[Current rule]
Use built-in Astro/Starlight capabilities first. Add plugins only when a demonstrated need justifies them.
:::
